# Source and authorship

This is Shadgy's maintenance fork of Ashen Builds for Turtle WoW.

- Original addon credit: The Ashen Banner, Tracer96 and the contributors recorded in Git history.
- Source repository: https://github.com/Tracer96/AshenBuilds
- Starting revision: `bd141a5811be0ccd6b57f886f2680e7a7bddc6bb` (2026-09-30).
- Original release repository: https://github.com/Tracer96/AshenBuild-Releases
- Fork repository: https://github.com/Shadgy/AshenBuilds

The starting revision includes upstream work merged after the original v1.0.0 ZIP:
per-character planner defaults, usable-item and armor-type filtering, community sync
fixes and talent-tree background art. These changes are credited to upstream.

At the time this fork was created, the source repository did not contain a LICENSE
file. This fork preserves the original credits and does not add a license or claim
ownership of the upstream code, embedded database, or artwork.

`BUILD-INFO.json` in each generated installation ZIP records the exact fork revision
and whether it was built from a modified checkout. The original Git history is retained.
